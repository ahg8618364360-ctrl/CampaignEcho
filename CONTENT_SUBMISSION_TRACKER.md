## 2. Pre-Formatted Social Media Copy (LinkedIn / Professional)

### Ready-to-Publish LinkedIn Post Template (Strictly Zero Banned Words)

> Most generative AI marketing tools suffer from catastrophic amnesia.
> 
> When marketers run a campaign, postmortems are filed away in forgotten spreadsheets. When they draft the next launch, the AI model starts from zero—unaware of what converted last week or which creative hooks tanked.
> 
> We built **CampaignEcho** to solve this continuous learning challenge using **Vectorize Hindsight**.
> 
> 🧠 **What makes it different?**
> Instead of generic vector retrieval, CampaignEcho implements a cognitive memory loop:
> 1. **Recall**: Dynamically pulls past campaign outcomes matching new brief parameters.
> 2. **Reflect**: Synthesizes cross-campaign heuristics (e.g., late-night flash drops outperforming static ads).
> 3. **Retain**: Permanently encodes postmortem performance data into brand-isolated memory banks.
> 
> When a campaign concludes, entering conversion metrics immediately closes the loop with verified real-time retention in Vectorize Hindsight Cloud.
> 
> Built with FastAPI, Next.js 15 App Router, and a resilient dual-engine LLM router (Z.ai GLM-4.5-Flash + Groq failover).
